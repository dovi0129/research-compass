# 화면 캡처

실제 모델·실데이터로 띄운 화면을 찍은 것이다. 합성 화면·목업이 아니다.

| 접두어 | 설계 차수 | 근거 | 내용 |
|---|---|---|---|
| `ui6_*` | 9차 | D-036·D-037 | 행정 네이비 팔레트, 검색 방식 4개, 수치 띠, 바닥글. 라이트·다크·760px·모드별·결과 화면 |
| `theme_probe_*` | 화면 모드 확인 | D-036 추기 2 | 라이트 / 다크 / 시스템 전환 |

## ⚠ 발표자료에 쓰기 전에

**남아 있는 `ui6_*` 도 현재 화면과 다르다.** 9차 설계를 찍은 것이고, 그 뒤 11차(D-038)에서
**첫 화면/결과 화면 전환을 없애고 한 페이지로 바꿨다.** 지금은 검색 상자가 그 자리에 남고 그 아래에 결과가 붙는다.

→ 슬라이드에 넣을 화면은 **직접 띄워서 찍는다.** 띄우는 방법은 `README.md` 「빠른 시작」.

찍을 때 — 브라우저 확대 100%, 창 너비 1,320px 이상(좁으면 두 단이 한 단으로 접힌다).
프로젝터를 쓸 거면 라이트 모드로(화면 맨 아래 `화면 모드`).

## 지운 캡처

옛 설계 차수의 캡처 65장(14.6MB)은 저장소에서 지웠다 — `ui_*`(최초 화면) · `ux_l*`(UX-L 조건) ·
`ui2_*`(D-029) · `ui3_*`(D-031) · `ui4_*`(D-033) · `ui5_*`(D-035, paper & indigo 팔레트).
전부 현재 화면과 팔레트·구조가 다르고 용량이 저장소의 대부분이었다.

**커밋 `82ab1b6` 에 그대로 있다.** `docs/decisions.md`·`reports/handoff.md` 가 근거로 인용한 캡처를 보려면:

```bash
git show 82ab1b6:reports/screenshots/ui5_02_results_light.png > ui5_02.png
```

## 캡처 방법

헤드리스 Edge 로 찍던 스크립트(`reports/ux_study/rc_*.py`)는 **삭제했다.**
자식 프로세스가 회차마다 남아 컴퓨터가 멈춘 적이 있다(2026-09-14, 임시 프로필 59개). 같은 커밋에서 볼 수 있다.

지금은 브라우저에서 직접 찍는다. 화면 검증은 `pytest tests/unit/test_app.py`(AppTest)로 한다.
