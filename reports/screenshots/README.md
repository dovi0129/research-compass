# 화면 캡처 목록

실제 모델·실데이터로 띄운 화면을 찍은 것이다. 합성 화면·목업이 아니다.

## ⚠ 발표자료에 쓰기 전에 읽을 것

**가장 새 캡처(`ui6_*`)도 현재 화면과 다르다.** `ui6_*` 는 9차 설계(D-036·D-037)이고,
그 뒤 11차(D-038)에서 **첫 화면/결과 화면 전환을 없애고 한 페이지로 바꿨다.**
지금 화면은 검색 상자가 그 자리에 남고 그 아래에 결과가 붙는다.

→ 슬라이드에 넣을 화면은 **직접 띄워서 찍는다.** 절차는 `docs/handover.md` §3.

## 세대별

| 접두어 | 설계 차수 | 근거 | 지금 화면과의 차이 |
|---|---|---|---|
| `ui_*` | 최초 화면 | D-025 | 전면 재설계 이전. 참고용 |
| `ux_l_*` | UX-L 비교 조건 | D-028 | 목록 전용 조건(사용성 비교용). 본 화면이 아니다 |
| `ui2_*` | 재설계 1차 | D-029 | 정보구조·라이트/다크 도입 |
| `ui3_*` | 3차 검토 | D-031 | 첫 화면 검색칸만, 부가 기능 제거 |
| `ui4_*` | 7차 검토 | D-033 | 선택한 과제 비교를 레코드 사실 표로 |
| `ui5_*` | 8차 | D-035 | 연구 작업공간 톤. paper & indigo 팔레트(**지금 팔레트 아님**) |
| `ui6_*` | 9차 | D-036·D-037 | **가장 최신.** 행정 네이비·검색 방식 4개·수치 띠·바닥글. 단 화면 전환 구조가 남아 있다 |
| `theme_probe_*` | 화면 모드 확인 | D-036 추기 2 | 라이트/다크/시스템 전환 재현 |

`ux_l2_*`·`ux_l3_*` 는 같은 차수의 UX-L 조건 캡처다.

## 캡처 방법

`reports/ux_study/rc_*_shots.py`·`rc_*_probe.py` 는 **헤드리스 Edge 를 띄우는 스크립트이고, 실행 금지다.**
자식 프로세스가 회차마다 남아 컴퓨터가 멈춘 적이 있다(2026-09-14, 임시 프로필 59개). 기록으로만 남겨 둔다.

지금은 브라우저에서 직접 찍는다. 화면 검증은 `pytest tests/unit/test_app.py`(AppTest)로 한다.
