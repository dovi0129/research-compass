# Research Compass 사용 설명서

화면을 순서대로 따라 하는 사용법입니다. 시연 진행과 **발표자료 준비**에 그대로 참고할 수 있게 썼습니다.

- 기준일 2026-09-14. 화면 문구는 현재 구현된 그대로 인용했습니다.
- 기능이 무엇이고 왜 그렇게 정했는지는 `reports/feature_specification.md`, 실행·중지는 `docs/run_server.md` 를 보세요.
- **8절(말할 때 쓰면 안 되는 표현)과 9절(시연 대본)이 발표자료용입니다.**

---

## 0. 한눈에 — 다섯 단계

| 단계 | 화면에서 하는 일 | 얻는 것 |
|---|---|---|
| 1 | 연구주제를 한 문장으로 쓰고 **탐색** | 제목이 유사한 과제 5건(최대 10건) |
| 2 | **탐색 관점**을 바꾸거나 **현재 검색문**을 직접 고쳐 다시 탐색 | 같은 주제를 다른 각도로 본 결과 |
| 3 | 카드를 읽고 **검색 근거 보기**로 순위·점수 확인 | 이 결과가 어떻게 나왔는지 |
| 4 | 참고할 과제를 **비교함**에 담아 **선택한 과제 비교** 표로 확인 | 어느 탐색에서 찾았는지 + 기관·연도·사업 |
| 5 | **탐색 메모**에 쓰고 저장 | Markdown 메모 · JSON 전체 기록 |

한 문장 요약: **연구주제와 제목 의미가 가까운 지원과제를 찾아, 몇 건을 골라 나란히 비교하고, 그 과정을 메모로 남기는 도구입니다.**

## 1. 시작 전

### 실행

```powershell
.venv\Scripts\python.exe -m streamlit run app.py --server.address 127.0.0.1 --server.port 8765
```

<http://127.0.0.1:8765> 로 접속합니다. 브라우저는 자동으로 열리지 않습니다.

### 반드시 예열하세요

첫 접속에서 검색칸이 뜨기까지 **약 23초**(모델·인덱스 적재), 첫 검색은 **약 4초**(재정렬기 적재)가 걸립니다.
이후 검색은 4~5초입니다. **시연 전에 접속 1회 + 검색 1회**를 미리 해 두세요. 안 하면 발표 중에 20초를 기다립니다.

### 첫 화면

위에서 아래로: `Research Compass / 한국연구재단 지원과제 탐색` → 왼쪽 **검색 상자**(검색 방식 네 개 → 검색칸 → **검색 범위**: 선정년도 · 대사업명 · 짧은 제목 제외)
와 오른쪽 **수록 데이터 구성**(선정연도별 · 대사업명별 수록 레코드 막대) → 수치 띠(`11,783 수록 레코드 · 2023~2025년 · 11 대사업명 · 749 주관기관명 · 851 연구분야명`) →
출처 바닥글. 설명 문장은 없습니다. 오른쪽 막대는 전체 수록 데이터의 구성이며 지원 규모의 증감으로 읽지 않습니다.

| 검색 방식 | 무엇을 넣나 | 실행되는 것 |
|---|---|---|
| **연구주제 한 문장** | 주제 한 문장 | 관점 `전체 연구주제`로 검색 1회 |
| **요소별 탐색** | 주제 + 대상·맥락 / 방법·접근 / 목표·질문 + 관점 선택 | 고른 관점 하나로 검색 1회 |
| **연구 요약 붙여넣기** | 연구 요약·계획 문단(1,000자까지) | 문단 전체가 검색문. 임베더 한도(512토큰)를 넘으면 잘라 검색하지 않고 멈춤 |
| **연구분야로 찾기** | 주제 문장 | 이름이 가까운 연구분야(D2) 8개. `연구주제로 넣기`는 넣기만 하고 검색은 직접 |

- 검색 범위는 **검색 전에** 정합니다. 여기서 고른 범위가 첫 검색에 적용되고 결과 화면의 `검색 범위`에도 남습니다.
- 수치 띠의 `대사업명`·`주관기관명`은 수록 데이터에서 **구별되는 이름의 수**입니다. 실제 기관 수와 같다고 보지 않습니다.
- 맨 위 네이비 띠는 출처(한국연구재단 공공데이터 — 과제정보 · 선정과제 연구분야)와 성격(공모전 출품작)만 밝힙니다. 기관 공식 서비스가 아닙니다.
- **화면 모드**(시스템·라이트·다크)는 페이지 맨 아래 `기능 상태` 밑에 작은 글자로 있습니다(창을 닫기 전까지 유지).
- `연구분야로 찾기` 결과의 `(비교 불가)`에 마우스를 올리면 선정횟수를 분야 간 비교에 쓰지 않는 이유가 나옵니다.
- 데이터나 인덱스가 없으면 검색을 막고 복구 명령을 보여 줍니다. **이때 가짜 결과를 대신 보여주지 않습니다.**
- 첫 화면과 결과 화면이 따로 없습니다. 검색 뒤에도 이 골격이 그대로 남고 결과만 아래에 붙습니다.
- 왼쪽 위 `Research Compass`를 누르면 **기본 화면**(결과·비교함을 숨긴 모습)으로 돌아옵니다. 탐색 이력·비교함·메모는 남고 `이전 결과로 돌아가기`로 복귀합니다.
  여기서 다른 문장을 내면 새 연구주제가 됩니다. 모두 지우려면 맨 아래 `기능 상태 › 작업공간 초기화`.

## 2. 단계 1 — 연구주제 입력

검색 방식 `연구주제 한 문장`에서 연구주제를 **한 문장으로** 씁니다. Enter 또는 `탐색`.
(요약 문단이 있으면 `연구 요약 붙여넣기`, 대상·방법·목표가 나눠져 있으면 `요소별 탐색`이 같은 일을 합니다.)

| | |
|---|---|
| 좋은 입력 | `지역 소멸 위기 대응 주민 참여 거버넌스` — 대상·문제·접근이 한 문장에 있음 |
| 아쉬운 입력 | `거버넌스` — 한 낱말은 의미가 넓어 결과가 흩어집니다 |

**안에서 일어나는 일** — 입력 문장을 임베딩해 11,783건의 **과제 제목** 임베딩과 비교하고(FAISS 내적),
후보 100건 중 상위 20건을 재정렬기로 다시 정렬한 뒤 위에서부터 보여 줍니다.
기관명·연구자·사업명은 임베딩에 넣지 않습니다. **제목 한 줄만 비교합니다.**

## 3. 단계 2 — 탐색 관점과 검색문

화면은 하나입니다 — 검색하면 검색 상자 **아래 같은 자리**에 결과가 붙고, 위쪽 검색 상자는 그대로 남습니다.
첫 검색 뒤 `연구주제 한 문장` 탭은 위에 `탐색 관점`, 아래에 `[현재 검색문] [탐색]` 두 줄로 바뀝니다(어느 탭에서 검색했든 결과가 나오면 이 탭으로 돌아옵니다).
오른쪽 패널은 `수록 데이터 구성`에서 `비교함`으로 바뀝니다.

### 탐색 관점 세 가지

| 관점 | 검색문이 되는 것 |
|---|---|
| **전체 연구주제** | 입력한 주제 문장 그대로 |
| **방법·접근** | `방법·접근` 요소 (+ `목표·질문` 요소가 있으면 이어서) |
| **대상·문제** | `대상·맥락` + `목표·질문` 요소 |

- 관점은 **검색문을 바꾸는 제안**입니다. 고른다고 바로 검색되지 않고, `탐색` 을 눌러야 실행됩니다.
- 방법·접근이나 대상·문제를 고르면 `탐색 요소 조정` 에 낱말을 넣어야 합니다. 요소가 없으면 안내만 나오고 검색은 실행되지 않습니다.
- **여러 관점을 한꺼번에 돌리거나 결과를 합치지 않습니다.** 관점 하나에 검색 한 번입니다.

### 탐색 요소 조정 (접힘)

`대상·맥락` / `방법·접근` / `목표·질문` 각 한 개씩 직접 적고 `요소 반영`. 자동 추출은 하지 않습니다.
이 요소는 관점 검색문의 재료이자, 나중에 `요소별 제목 표현 비교` 의 기준이 됩니다.

### 현재 검색문

**검색에 그대로 들어가는 문장**입니다. 직접 고쳐도 되고, 낱말을 자동으로 늘리지 않습니다.
관점이 제안한 문장과 다르면 아래에 `직접 수정됨` 칩과 `관점 제안: "…"` 이 붙습니다.

### 검색 범위

검색 상자 아래쪽 한 줄 — 선정년도·대사업명(여러 개 선택 가능), 짧은 제목 제외. 검색 전에 정해도 되고, 검색 뒤 바꾸면 그 줄 아래
`이 범위로 다시 탐색` 이 나타납니다. 진행 표시와 결과는 검색 상자 아래 같은 자리에 나옵니다.

### 새 연구주제

`연구주제 한 문장` 탭의 칸은 검색 뒤 **현재 검색문**입니다(고치면 검색문만 바뀜). 연구주제 자체를 바꾸려면 `요소별 탐색` 탭의 연구주제 칸이나
`연구 요약 붙여넣기` 탭을 씁니다. 이전 결과·비교함·메모는 지워지지 않고 이전 결과에는 `이전 연구주제의 결과` 표시가 붙습니다.

### 최근 탐색

두 번 이상 탐색하면 칩이 생깁니다. 칩을 누르면 **다시 검색하지 않고** 그 결과로 표시만 바꿉니다.

## 4. 단계 3 — 결과 읽기

절 제목은 `제목이 유사한 과제`, 옆에 표시 건수. 그 아래 한 줄:
**"제목의 의미만 비교한 결과입니다. 연구내용은 원문에서 확인하세요."**

카드 한 장 = 순번 · 과제명 원문 · 기관 · 선정연도 · 대사업명 · **의미 유사도 0.xxx**.

### 의미 유사도 읽는 법

| 이렇게 읽습니다 | 이렇게 읽으면 틀립니다 |
|---|---|
| 내 검색문과 이 제목이 **의미상 가까운 정도** (0~1 상대 점수) | ❌ 정확도 · 일치율 · 관련 확률 |
| 0.66 이 0.59 보다 **더 가깝다** | ❌ 66% 관련 있다 |
| 값이 높아도 **읽어 보고 판단할 후보**일 뿐 | ❌ 관련 과제로 확정 |

참고로 실측(2026-09-09, warm): `지역 소멸 위기 대응 주민 참여 거버넌스` 의 상위 5건이 0.589~0.663,
전체 분포의 상위 1% 경계가 0.501 이었습니다. **"대다수 과제보다 가깝다"는 뜻이지 관련성 판정이 아닙니다.**

### 검색 근거 보기

카드마다 있는 버튼입니다. 다섯 가지를 밝힙니다. (관련도 기준값이 확정되지 않아 "기준값 이상/미만" 행은 지금 없습니다 — 관련 여부를 가르는 값은 아직 없다는 뜻입니다.)

| 항목 | 뜻 |
|---|---|
| 최종 표시 순위 | 이 목록의 순서 (재정렬 점수 순) |
| 1차 의미검색 위치 | **재정렬 전** 11,783건 중 유사도 위치. 최종 순위와 **다를 수 있습니다** |
| 의미 유사도 | 0~1 상대 점수 |
| 재정렬 점수 | 최종 순서를 정한 값. 확률·정확도가 아님 |
| 원본 행 · 레코드 ID · 스냅샷 | 원본 데이터의 몇 번째 행인지. 원본 데이터 페이지 링크 |

> 두 순위를 일부러 다르게 보여 줍니다. 의미검색이 30위로 올린 과제를 재정렬기가 2위로 올릴 수 있습니다.
> 감추면 "왜 이게 위에 있지?"에 답할 수 없습니다.

### 더 보기

기본 5건, `더 보기` 로 5건씩 최대 10건. 범위를 통과한 결과가 없으면 빈 칸을 채우지 않고 그렇게 말합니다.

## 5. 단계 4 — 비교함과 비교표

### 담기

카드의 `비교함에 담기` → 오른쪽 `비교함` 패널에 `E1`, `E2` … 순서대로 쌓입니다(최대 5건).
비교함 아래 `표시 중인 N건의 구성`은 지금 보이는 결과의 선정연도·대사업명 구성입니다(표시 수가 바뀌면 함께 바뀜).
담은 것은 `✓ 담김` 으로 바뀝니다. `빼기` 는 비교함에서만 빼고 검색 결과에서는 사라지지 않습니다.

- 검색을 새로 해도 비교함은 유지됩니다. 지금 결과에 없는 과제에는 `지금 보는 결과에 없음` 이 붙습니다.
- 같은 과제를 두 번 담을 수 없습니다.

### 선택한 과제 비교

**2건 이상**부터 표가 나타납니다. 과제가 열, 아래가 행입니다.

| 행 | 내용 |
|---|---|
| 탐색 관점 | 어느 관점의 탐색에서 찾았는지 (여러 번이면 ①② 로 모두) |
| 검색문 | 그때 실제로 검색한 문장 |
| 당시 순위 | 그 결과에서 몇 위였는지 |
| 선정연도 · 사업 · 기관 | 원본 값. 사업은 대사업 › 중사업 › 소사업 › 세부사업 |
| 원본 위치 | 원본 데이터 페이지 링크 + 원본 행 번호 |

- **의미 유사도는 이 표에 없습니다.** 검색문마다 기준이 달라 나란히 비교하면 안 되는 값입니다.
- 접힘 `수록 데이터 기준 참고` 에 같은 사업·같은 기관의 **수록 레코드 수**(연도별 포함)가 있습니다.
  "과제 수"가 아니라 "수록 레코드 수"이고, **연도별 차이는 지원 규모의 증감을 뜻하지 않습니다.**

## 6. 단계 5 — 탐색 메모

`탐색 메모` 의 칸에 직접 씁니다. 자동 요약·해석은 만들지 않습니다.

| 버튼 | 파일 | 내용 |
|---|---|---|
| 탐색 메모 저장 | `research_compass_memo.md` | 연구주제 → 선택한 과제(제목·기관·연도·사업·찾은 검색·원본 링크) → 탐색 기록 → 내가 쓴 메모 |
| 전체 작업기록 백업 | `research_compass_workspace.json` | 모든 검색 실행·선택·관측·출처 manifest·원문 해시 |

- **메모는 현재 브라우저 세션에만 유지되며 서버에 저장되지 않습니다.** 남기려면 내려받으세요.
