# 시험용 합성 데이터

**여기 있는 CSV 는 실제 공공데이터가 아니다.** 시험(`pytest`)과 파이프라인 점검에만 쓴다.

| 파일 | 내용 |
|---|---|
| `D1_fixture.csv` | D1(과제정보)과 같은 컬럼 구성의 합성 61행 |
| `D2_fixture.csv` | D2(선정과제 연구분야)와 같은 컬럼 구성의 합성 몇 행 |

`D1_fixture.csv` 에는 원본과 컬럼을 맞추려고 `연구책임자명`·`연구자번호` 칸이 있지만
값은 전부 지어낸 것이다 — 이름은 `홍길동` 하나, 번호는 `1000000`부터 이어지는 연번,
기관은 실재 여부와 무관한 세 개, 과제명도 지어낸 문장이다. **실제 개인정보가 아니다.**

실제 원본에서는 이 두 컬럼을 정제 단계에서 제거한다(`prepare` 가 assert 로 검증).
정제 결과·인덱스·화면·메모 어디에도 남지 않는다.

쓰는 법:

```bash
python -m research_compass.cli --config config/fixture.yaml audit
```

결과 예시는 `reports/_sample_fixture/` 에 있다.
